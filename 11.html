11.1Norms

Let \(x\) be a real number. I define its absolute value as \[ |x|=\begin{cases} x, & \mbox{if } x\geq 0, \\ -x, & \mbox{otherwise}. \end{cases} \]

Absolute value has several nice properties. In particular I have that \(|x|> 0\) for all non-zero \(x\), and is equal to zero only if \(x=0\); for any real number \(\alpha\) I have that \(|\alpha x|=|\alpha|\cdot|x|\); and finally, for any \(x,y\in\R\) I have the so-called triangle inequality \begin{equation}\label{eq11:1} |x+y|\leq |x|+|y|. \end{equation}

Exercise 11.1. Give a proof for the triangle inequality.

The name triangle inequality refers to the fact that absolute value allows one to measure the distance \(d\) between any two real numbers, viz., \(d(x,y)=|x-y|\), and the distance certainly satisfies \[ |x-y|=|x-z+z-y|\leq |x-z|+|z-y|, \] i.e., the distance from \(x\) to \(y\) is no bigger than the distance from \(x\) to some other number \(z\) plus the distance from \(z\) to \(y\). Geometrically, the length of one of the sides of a triangle cannot be bigger than the sum of the lengths of the two other sides. Hence the name.

To reiterate, the absolute value allows me to measure the distance between any two points, and also measure the size of a given real number \(x\), which is the distance from zero. It would be very rewarding to be able to do something similar with the elements of \(\R^n\), which is the \(n\)-dimensional vector space, where the elements are column-vectors with \(n\) coordinates: \[ \R^n\ni \bs x=\begin{bmatrix} x_1 \\ \vdots \\ x_n \\ \end{bmatrix},\quad x_j\in\R. \] This is done by using a norm.

Definition 11.1. A norm on the vector space \(\R^n\) is a function \[ \|\cdot\|\colon\R^n\longrightarrow \R, \] such that

  1. \(\|\bs x\|\geq 0\), for any \(\bs x\in\R^n\), and \(\|\bs x\|=0\) if and only if \(\bs x=\bs 0\), the zero vector;

  2. if \(\alpha\in\R\) then \(\|\alpha \bs x\|=|\alpha|\cdot\|\bs x\|\) for any \(\bs x\in\R^n\);

  3. \(\|\bs x+\bs y\|\leq\|\bs x\|+\|\bs y\|\) for any \(\bs x,\bs y\in\R^n\) (triangle inequality).

Example 11.2. Let \[ \|\bs x\|_1=\sum_{i=1}^n |x_i|. \] Let me check all the norm axioms. First, clearly, \(\|\bs x\|_1\geq 0\) as the sum of nonnegative terms; if \(\bs x=\bs 0\) then \(\|\bs x\|_1=0\), also, if \(\|\bs x\|_1=0\) then each coordinate \(x_i\) must be zero, and hence \(\bs x=\bs 0\). To check the second axiom I compute \[ \|\alpha\bs x\|_1=\sum_{i=1}^n|\alpha x_i|=|\alpha|\sum_{i=1}^n |x_i|=|\alpha|\cdot \|\bs x\|_1 \] as required.

For the triangle inequality \[ \|\bs x+\bs y\|_1=\sum_{i=1}^n|x_i+y_i|\leq \sum_{i=1}^n\bigl(|x_i|+|y_i|\bigr)=\sum_{i=1}^n|x_i|+\sum_{i=1}^n|y_i|=\|\bs x\|_1+\|\bs y\|_1. \] So I have my first legitimate example of a norm.

Example 11.3. \[ \|\bs x\|_2=\left(\sum_{i=1}^n x_i^2\right)^{\frac 12}, \] which is usually called the Euclidean norm. The first two axioms are checked exactly as in the previous example. The triangle inequality is less obvious; it follows from the Cauchy–Schwarz inequality \[ \left|\sum_{i=1}^n x_iy_i\right|\leq \|\bs x\|_2\,\|\bs y\|_2. \]

Exercise 11.2. Use the Cauchy–Schwarz inequality to prove the triangle inequality for \(\|\cdot\|_2\). Hint: compute \(\|\bs x+\bs y\|_2^2\).

Example 11.4. \[ \|\bs x\|_\infty=\max_{i}|x_i|. \]

I invite you to check the norm axioms for this example.

In short, it is possible to come up with different specific definitions of vector norms.

Example 11.5 (Unit ball in \(\R^2\)). The unit ball, i.e., the ball of radius 1, is the set of vectors \(\bs x\in\R^2\) such that \(\|\bs x\|\leq 1\), and its shape depends on the chosen norm (see Fig. 11.1). For \(\|\cdot\|_1\) the condition \(|x_1|+|x_2|\leq 1\) gives a “diamond”, i.e., a square rotated by \(45^\circ\), with the vertices \((\pm 1,0)\) and \((0,\pm 1)\); for \(\|\cdot\|_2\) the condition \(x_1^2+x_2^2\leq 1\) gives the usual disk; and for \(\|\cdot\|_\infty\) the condition \(\max\{|x_1|,|x_2|\}\leq 1\) gives the square \([-1,1]\times[-1,1]\). Note that the three balls are nested, which reflects the inequalities \(\|\bs x\|_\infty\leq\|\bs x\|_2\leq\|\bs x\|_1\).

Since I work in \(\R^n\), matrices \(\bs A=[a_{ij}]_{n\times n}\) for me are not elements of \(\R^n\) (they can be considered as elements of \(\R^{n^2}\)) but maps acting on \(\R^n\), i.e., \[ \bs A\colon \R^n\longrightarrow \R^n, \] where it simply means that for any vector \(\bs x\in\R^n\) I can compute \(\bs{Ax}\in \R^n\), which in coordinates is a matrix times vector multiplication. My goal is to define “a size” or a norm of a matrix as well.

Of course, I could have generalized the examples given above to \(\R^{n^2}\) (for instance, the Euclidean norm of the vector of all \(n^2\) elements of \(\bs A\) is called the Frobenius norm \(\|\bs A\|_F\)), but for my purposes I need something that is directly related to the chosen vector norm. This is achieved by the so-called subordinate norm of a matrix; you can read more in any linear algebra book, and for my purposes I will just need the definitions.

Definition 11.6. Let \(\|\cdot\|\) be a norm on \(\R^n\). The subordinate norm of matrix \(\bs A\) is \[ \|\bs A\|=\max_{\bs x\neq\bs 0}\frac{\|\bs{Ax}\|}{\|\bs x\|}\,. \]

For the vector norms \(\|\cdot\|_\infty\) and \(\|\cdot\|_1\) this definition leads to the following explicit formulas, which I state without proof. The subordinate infinity norm of matrix \(\bs A\) is \[ \|\bs A\|_\infty = \max_i \sum_{j=1}^n |a_{ij}|\quad \mbox{(largest row sum)}, \] and the subordinate 1-norm of matrix \(\bs A\) is \[ \|\bs A\|_1 = \max_j \sum_{i=1}^n |a_{ij}|\quad \mbox{(largest column sum)}. \] Note that \(\|\bs A\|_1=\|\bs A^\top\|_\infty\). For the subordinate norms all the usual axioms of norms hold (you can check them for the given two examples). Additionally, directly from the definition, for any subordinate norm I have \[ \|\bs{Ax}\|\leq \|\bs A\|\cdot\|\bs x\|,\quad \|\bs{AB}\|\leq \|\bs A\|\cdot\|\bs B\|,\quad \|\bs I\|=1. \] Here and below if I do not specify which norm I use, it means it is true for any vector norm and its subordinate counterpart. Note that the Frobenius norm is not subordinate to any vector norm, since \(\|\bs I\|_F=\sqrt n\neq 1\).

The matrix norm subordinate to the Euclidean norm \(\|\cdot\|_2\) is more difficult to compute: it can be shown that \(\|\bs A\|_2=\sqrt{\lambda_{\max}}\), where \(\lambda_{\max}\) is the largest eigenvalue of the matrix \(\bs A^\top\bs A\). I will not use it in my computations by hand, but it is the default choice in NumPy (see below).

11.2Condition number of a matrix

Let me go back to the system of linear algebraic equations \[ \bs{Ax}=\bs b. \] Here \(\bs A\) and \(\bs b\) are input data of our problem, and \(\bs x\) is the output, our solution. In reality all the data is known only approximately, up to the measurement error. Therefore it is natural to ask what kind of error we may expect in our solution if we can estimate the error in the input data.

To be precise, let me assume that instead of the exact vector \(\bs b\) I know only its approximate measurement \(\bs b+\Delta \bs b\). Here \(\|\Delta\bs b\|\) is the absolute error, and \[ \frac{\|\Delta\bs b\|}{\|\bs b\|} \] is the relative error. Using \(\bs b+\Delta\bs b\) instead of \(\bs b\) will cause me to compute something like \(\bs x+\Delta\bs x\), where \(\Delta \bs x\) is the absolute error in my solution.

Consider the following line of equalities and inequalities, where I use the properties of norms and the fact that \(\bs{Ax}=\bs b\). \begin{align*} \bs A(\bs x+\Delta\bs x) & =\bs b+\Delta\bs b\implies \\ \bs A\bs x+\bs A\Delta\bs x & =\bs b+\Delta\bs b\implies \\ \bs A\Delta\bs x &=\Delta\bs b \implies\\ \Delta\bs x&=\bs A^{-1}\Delta\bs b\implies\\ \|\Delta \bs x\|&=\|\bs A^{-1}\Delta\bs b\|\leq\|\bs A^{-1}\|\cdot\|\Delta\bs b\|=\\ &=\|\bs A^{-1}\|\cdot\|\Delta\bs b\|\frac{\|\bs b\|}{\|\bs b\|}=\\ &=\|\bs A^{-1}\|\cdot\|\bs{Ax}\|\frac{\|\Delta\bs b\|}{\|\bs b\|}\leq\\ &\leq \|\bs A^{-1}\|\cdot\|\bs{A}\|\cdot\|\bs x\|\frac{\|\Delta\bs b\|}{\|\bs b\|}\implies\\ \frac{\|\Delta\bs x\|}{\|\bs x\|}&\leq \|\bs A^{-1}\|\cdot\|\bs{A}\|\cdot \frac{\|\Delta\bs b\|}{\|\bs b\|}\,. \end{align*} In words, the relative error in my solution is bounded by the relative error in vector \(\bs b\) times \(\|\bs A\|\cdot\|\bs A^{-1}\|\).

Let me consider another situation, when I have measurement error in the matrix \(\bs A\) itself, i.e., I know \(\bs A+\Delta\bs A\) instead of the exact \(\bs A\). I have \begin{align*} (\bs A+\Delta\bs A)(\bs x+\Delta\bs x) & =\bs b\implies \\ \bs A\bs x+\Delta \bs A(\bs x+\Delta\bs x)+\bs A\Delta\bs x & =\bs b\implies \\ \bs A\Delta\bs x & =-\Delta\bs A(\bs x+\Delta\bs x)\implies \\ \Delta\bs x & =-\bs A^{-1} \Delta\bs A(\bs x+\Delta\bs x)\implies\\ \frac{\|\Delta\bs x\|}{\|\bs x+\Delta \bs x\|} & \leq \|\bs A\|\cdot\|\bs A^{-1}\|\cdot \frac{\|\Delta\bs A\|}{\|\bs A\|}\,, \end{align*} which leads to a similar conclusion: my relative error in the solution is bounded by the relative error in the data times the same expression \(\|\bs A\|\cdot\|\bs A^{-1}\|\). Note that here the error \(\Delta\bs x\) is compared with the computed solution \(\bs x+\Delta\bs x\), and not with the exact one; if the errors are small, the difference between these two relative errors is small as well. If both \(\bs A\) and \(\bs b\) have errors, a similar (somewhat more involved) computation shows that, as long as \(\kappa(\bs A)\|\Delta\bs A\|/\|\bs A\|\) is small, the relative error of the solution is bounded by approximately \[ \|\bs A\|\cdot\|\bs A^{-1}\|\left(\frac{\|\Delta\bs A\|}{\|\bs A\|}+\frac{\|\Delta\bs b\|}{\|\bs b\|}\right). \] This prompts me to introduce the following definition.

Definition 11.7. For a nonsingular matrix \(\bs A\) its condition number \(\kappa (\bs A)\) is defined as \[ \kappa(\bs A)=\|\bs A\|\cdot\|\bs A^{-1}\|. \]

Note that \[ 1=\|\bs I\|=\|\bs A\bs A^{-1}\|\leq \|\bs A\|\cdot\|\bs A^{-1}\|, \] that is, \(\kappa(\bs A)\geq 1\) for any nonsingular matrix \(\bs A\).

Now I can reformulate my conclusions from the computations above as follows: for a matrix with a large condition number it is possible to have a large relative error in the solution even if the relative error of the initial data is small. Because of this possibility, matrices for which \(\kappa(\bs A)\gg 1\) are called ill-conditioned. For ill-conditioned matrices one cannot expect that direct methods like the \(\bs{LU}\) factorization will give a solution close to the exact one, because of rounding errors: even if the data are exact, they are stored in the computer with the relative error of about \(\epsilon\) (Section 10), and this error can be multiplied by \(\kappa(\bs A)\). This gives a useful rule of thumb: if \(\kappa(\bs A)\approx 10^p\), then one can lose up to \(p\) correct digits in the solution, so that with \(\epsilon\approx 10^{-16}\) only about \(16-p\) digits can be trusted. A good professional software for solving systems of linear equations should at least issue a warning if the user is dealing with an ill-conditioned matrix (see, however, the next subsection).

Note that the condition number has nothing to do with the size of the determinant, although it may seem natural to expect that a matrix with a small determinant is “almost singular”. Indeed, \(\kappa(\alpha\bs A)=|\alpha|\cdot\|\bs A\|\cdot|\alpha|^{-1}\|\bs A^{-1}\|=\kappa(\bs A)\) for any \(\alpha\neq 0\). For instance, the matrix \(0.1\,\bs I\) of size \(20\times 20\) has the determinant \(10^{-20}\), but its condition number is 1, the smallest possible, and the system with this matrix is solved with no loss of accuracy at all.

Example 11.8. Let me go back to the concluding exercise of Section 10 (Exercise 10.3), where I solved the system \[ \begin{aligned} x_1+x_2&=2,\\ x_1+1.2\,x_2&=2.2 \end{aligned} \] with the exact solution \(x_1=x_2=1\) in my toy number system, and got \(x_1=2\), \(x_2=0\). Here \[ \bs A=\begin{bmatrix} 1 & 1 \\ 1 & 6/5 \end{bmatrix},\quad \bs A^{-1}=\begin{bmatrix} 6 & -5 \\ -5 & 5 \end{bmatrix}, \] hence \(\|\bs A\|_\infty=11/5\), \(\|\bs A^{-1}\|_\infty=11\), and \[ \kappa_\infty(\bs A)=\frac{11}{5}\cdot 11=\frac{121}{5}\approx 24. \] When the data are stored in my toy system, they are rounded with the relative error up to \(\epsilon/2=1/8\), and hence the relative error in the solution can be as large as \(24\cdot 1/8\approx 3\), i.e., no correct digits can be expected. To be more precise, the actual data errors are \(\Delta\bs A=\begin{bmatrix}0&0\\0&1/20\end{bmatrix}\) (\(1.2\) was stored as \(5/4\)) and \(\Delta\bs b=(0,\,-1/5)^\top\) (\(2.2\) was stored as \(2\)), so that \[ \frac{\|\Delta\bs A\|_\infty}{\|\bs A\|_\infty}=\frac{1/20}{11/5}\approx 0.023,\quad \frac{\|\Delta\bs b\|_\infty}{\|\bs b\|_\infty}=\frac{1/5}{11/5}\approx 0.091, \] and the estimate above predicts the relative error up to about \(24.2\cdot(0.023+0.091)\approx 2.8\). The actual relative error of the computed solution \((2,0)^\top\) is \[ \frac{\|(2,0)^\top-(1,1)^\top\|_\infty}{\|(1,1)^\top\|_\infty}=1, \] i.e., \(100\%\): the computed solution has nothing to do with the exact one, in agreement with the estimate.

This example also answers the question from Exercise 10.3. In Example 10.3 the large error was caused by the algorithm: Gaussian elimination without pivoting amplified the rounding errors, although the problem itself was well-conditioned (check that its condition number is \(\kappa_\infty=17/5=3.4\)), and pivoting fixed it. One says that Gaussian elimination without pivoting is unstable. In the present example the problem itself is ill-conditioned: the data cannot even be stored without errors that are amplified 24 times, and no algorithm can help.

11.3Norms and condition numbers in Python

In NumPy the norms of vectors and matrices are computed by the function np.linalg.norm, and the condition number by np.linalg.cond; the second parameter specifies the norm (1, 2, or np.inf, which is infinity in NumPy). Let me check the computations from Example 11.8:

>>> x = np.array([1.0, -2.0, 2.0])
>>> np.linalg.norm(x, 1)
np.float64(5.0)
>>> np.linalg.norm(x)          # the norm 2 by default
np.float64(3.0)
>>> np.linalg.norm(x, np.inf)
np.float64(2.0)
>>> A = np.array([[1.0, 1.0], [1.0, 1.2]])
>>> np.linalg.inv(A)
array([[ 6., -5.],
       [-5.,  5.]])
>>> np.linalg.norm(A, np.inf)  # the largest row sum
np.float64(2.2)
>>> np.linalg.cond(A, np.inf)
np.float64(24.200000000000006)
>>> np.linalg.cond(A)          # the norm 2 by default
np.float64(22.15486318323298)

Note the inequalities \(\|\bs x\|_\infty\leq\|\bs x\|_2\leq\|\bs x\|_1\) for the vector \(\bs x\), and note that the condition number depends on the norm: by default NumPy uses the norm 2, and \(\kappa_2(\bs A)\approx 22.2\), whereas \(\kappa_\infty(\bs A)=24.2\). For most purposes the choice of the norm is not important, since we are only interested in the order of magnitude of \(\kappa(\bs A)\).

A classical example of ill-conditioned matrices is the Hilbert matrices \(\bs H_n\) with the elements \(h_{ij}=1/(i+j-1)\), \(i,j=1,\ldots,n\). As in Section 7, I choose the exact solution \(\bs{\hat x}=(1,\ldots,1)^\top\), compute \(\bs b=\bs H_n\bs{\hat x}\), solve the system \(\bs H_n\bs x=\bs b\), and compare the relative error of the solution with \(\kappa_\infty(\bs H_n)\,\epsilon\), which, according to the discussion above, estimates the effect of the rounding errors of the data.

import numpy as np

eps = np.finfo(float).eps


def hilbert(n: int) -> np.ndarray:
    """Return the n by n Hilbert matrix with h_ij = 1 / (i + j - 1)."""
    H = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            H[i, j] = 1 / (i + j + 1)       # Python indexes start from 0
    return H


for n in [4, 8, 12]:
    H = hilbert(n)
    x_hat = np.ones(n)                      # the exact solution
    b = H @ x_hat
    x = np.linalg.solve(H, b)
    kappa = np.linalg.cond(H, np.inf)
    error = np.linalg.norm(x - x_hat, np.inf) / np.linalg.norm(x_hat, np.inf)
    print(f"n = {n:2d}  kappa = {kappa:.1e}  kappa*eps = {kappa * eps:.1e}  error = {error:.1e}")
n =  4  kappa = 2.8e+04  kappa*eps = 6.3e-12  error = 5.4e-14
n =  8  kappa = 3.4e+10  kappa*eps = 7.5e-06  error = 7.2e-08
n = 12  kappa = 4.0e+16  kappa*eps = 8.9e+00  error = 2.8e-01

Since \(\kappa_\infty(\bs H_n)\) grows very fast with \(n\), the solution loses more and more correct digits: about 13 correct digits are left for \(n=4\), about 7 for \(n=8\), and for \(n=12\) there is not a single correct digit, although the matrix is only \(12\times 12\), the data are exact up to rounding, and the algorithm (the \(\bs{LU}\) factorization with partial pivoting) is the best available. Note that for \(n=4\) and \(n=8\) the actual errors are about a hundred times smaller than \(\kappa_\infty(\bs H_n)\,\epsilon\): the estimate gives the worst case, and the actual rounding errors usually partially cancel each other. The rule of thumb from the previous subsection should be understood in this sense.

Finally, a warning. The function np.linalg.solve does not warn the user about an ill-conditioned matrix: it reports an error only if the matrix is exactly singular, and for \(n=12\) it silently returned a solution without any correct digits. The function scipy.linalg.solve from the package SciPy, which otherwise does the same, issues a warning in this case (LinAlgWarning: An ill-conditioned matrix detected). In any case, if you are not sure that your matrix is well-conditioned, compute its condition number.
